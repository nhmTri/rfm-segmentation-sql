# Data provenance

Everything in this repository is **synthetic**.

`sql/00_sample_data.sql` creates ten invented orders across five invented customer IDs. It exists so the query runs for anyone who clones the repo, and so CI has something deterministic to assert against.

No client data, no customer records and no figures from any employer appear here. The method is the deliverable; the numbers quoted in the README come from work I cannot publish, and are stated as outcomes rather than reproduced as data.
